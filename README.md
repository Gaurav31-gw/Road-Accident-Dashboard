# 🚦 Road Accident Dashboard  

## 📊 Project Overview  
This project presents a **Road Accident Dashboard** built in **Tableau**, designed to analyze and visualize road accident data.  
The dashboard highlights accident trends, casualties, severity, and contributing factors such as weather, road surface, and location.  

The aim is to provide an **interactive and insightful representation** of road accident data for better decision-making and road safety awareness.
